# 会話用の用語集(下書き)— codex-collab

masuP9 と話すとき(スキルの結果報告・設計の相談)の言い換え表。
スキル本文(SKILL.md)の用語はそのままでよいが、**ユーザーへの説明では右の言い換えを使う**。
哲学・論理学・統計の語をカタカナや漢語に訳しただけで出さない。

## 1. スキル名

名前はそのまま使ってよい。初めて出すときは一言で説明を添える。

| スキル | 一言での説明 |
| --- | --- |
| contradiction-lift | Claude と Codex に別々に解かせ、食い違ったら「どういう条件ならどちらを選ぶか」のルールにまとめる |
| dialectic-loop | 仮説から予想を立て、実データで確かめ、仮説を直す、を繰り返す |
| strong-inference | 原因の候補を並べ、候補を消していける実験で絞り込む |
| devils-advocate | Claude が案を守り、Codex がわざと反対して弱点を探す |

## 4. 論理学・統計の語

「仮説」「演繹」「帰納」「止揚(アウフヘーベン)」は masuP9 に通じるので、そのまま使ってよい。
ただし演繹と帰納は取り違えやすいので、**毎回かっこで働きを添える**。
例:「演繹(予想を立てる)は Claude、帰納(データで確かめる)は Codex」

| 用語 | 会話での言い換え | 意味(一言) |
| --- | --- | --- |
| 仮説 | そのまま | たぶんこうだ、という仮の答え |
| 演繹 / deductive | 演繹(予想を立てる) | 「仮説が正しければデータにこう出るはず」を書き出す |
| 帰納 / inductive | 帰納(データで確かめる) | 実際のファイルやログを集計する |
| アブダクション / abduction | 仮説の候補を出す | データを見て「原因はこれかも」を複数挙げる |
| 仲裁 / arbiter | 突き合わせて判定する役 | 予想と結果を比べ、仮説を直す |
| 反証 / falsifier | 「こうなったら仮説は間違い」の条件 | |
| 競合仮説 | 原因の候補たち | |
| killer experiment / discriminating experiment | 候補を絞り込める実験 | 結果によってどちらか分かれる |
| コーパス / corpus | 確かめるための材料 | コード・ログ・会話履歴など |
| prior / prior-independence | AI のクセ / 別メーカーの AI を使うこと | |
| correlated blind spots / 共有盲点 | 両方の AI が同じ間違いをする危険 | |
| precision / recall / 偽陽性 / 偽陰性 | 使わない。必要なら「見逃し」「誤検出」 | |
| crux / EVI 期待情報価値 | 使わない | スキルにも出てこない |

## 5. 補足

- 専門用語はスキル本文にほぼ英語で書かれている。「止揚」「アポリア」「封緘解」「真理契機」などの日本語は README.md に集まっている。Claude はそれを読んで、訳した漢語で報告しがち。
- 用語が多いファイル:`skills/contradiction-lift/SKILL.md`、`skills/dialectic-loop/SKILL.md`、`commands/contradiction-lift.md`、`commands/dialectic-loop.md`、`README.md`
